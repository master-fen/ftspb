# Календарь турниров

Раздел `/tournaments`. Админки и таблиц в базе нет: турниры лежат статическим
модулем в репозитории, каждое обновление календаря — отдельный PR агента. Цель
этого периода — собрать требования к будущей сущности `Tournament`
(`docs/backlog.md`, «После запуска»); они копятся здесь, в последнем разделе.

## Где что лежит

- `src/data/tournaments.ts` — источники (`TOURNAMENT_SOURCES`) и записи
  (`TOURNAMENTS`). Записи — по строке на запись, в порядке исходной таблицы,
  под `// prettier-ignore`: обновление даёт построчный дифф.
- `src/lib/tournament-filters.ts` — значения `?place=` и `?age=`, подписи
  чипов, правила совпадения. Значений из модуля данных не импортирует (только
  типы) — см. «Устройство страницы».
- `src/lib/tournament-calendar.ts` — год, статус, деление на блоки, подписи
  сроков, возрастов, места и строк источников.
- `src/routes/_site.tournaments.tsx` — страница.
- `tests/tournaments-data.test.ts` — сторож данных;
  `tests/tournament-calendar.test.ts` — чистые функции.

## Поля

**Источник** — один календарь одной версии:

- `key` — ключ (`spb-2026`, `ftr-2026`, `ftr-2027`);
- `title` — название, как в строке источника на странице;
- `year` — год календаря: год даты начала каждой его записи (сторож);
- `months` — месяцы периода, если календарь охватывает не весь год
  (`spb-2026`: сентябрь — декабрь); `null` — весь год, и тогда период в строке
  не пишется: год уже есть в названии;
- `status` — «действующий» или «проект»;
- `versionDate` — дата версии строкой ДД.ММ.ГГГГ, выводится как есть.

Строка источника: «название[, период]. Версия от ДД.ММ.ГГГГ.» — у
действующего; «… Проект от ДД.ММ.ГГГГ, сроки могут измениться.» — у проекта.
Строки видны всегда, от фильтров не зависят, порядок — порядок массива.

**Запись** — одно соревнование:

- `sources` — ключи источников, один или несколько;
- `start`, `end` — даты ISO, включительно; длина не больше 7 дней (сторож);
- `ages` — возрасты из `9-10`, `до 13`, `до 15`, `до 17`, `до 19`,
  `взрослые`, без повторов;
- `title` — название;
- `city` — город;
- `venue` — база, необязательна; у записей календаря СПб обязательна (сторож);
- `russia` — всероссийское или международное соревнование.

Записи без `id`: сочетание полей без `sources` уникально (сторож), ключ строки
в разметке собирается из полей.

## Фильтры и блоки

- **Место.** «Все» (по умолчанию); «Санкт-Петербург» — город записи
  «Санкт-Петербург», из любого календаря; «Россия» — `russia: true`, любой
  город. Одна запись может попасть в оба фильтра.
- **Год** — год даты начала. Чипы — годы, которые есть в данных. По
  умолчанию — текущий год по Москве, если он есть в данных; иначе ближайший
  следующий; иначе последний (то же правило, что у `/federation/events`,
  `pickDefaultEventYear`).
- **Возраст.** «Все возрасты» (по умолчанию) или один возраст: запись видна,
  если он среди её возрастов.
- Состояние — в адресе: `?place=spb|russia`, `?age=9-10|u13|u15|u17|u19|adult`,
  `?year=`. Умолчания из адреса вырезаются: место и возраст —
  `stripSearchParams`, год — redirect из loader (умолчание зависит от даты,
  постоянным его не объявить), как на `/federation/events`. Год вне данных —
  тоже redirect на адрес без `?year=`.
- **Статус** — по дате по Москве (`todayInMoscow`, через loaderData, как на
  `/federation/events`): идёт — начало ≤ сегодня ≤ конец; завершён — конец
  раньше сегодня.
- **Блоки.** «Предстоящие» — идут сейчас и ещё не начались, от ранних к
  поздним по дате начала; «Завершённые» — от последних к ранним по дате
  начала. Пустой блок не показывается; если пусты оба — «Турниров по
  выбранным условиям нет.»
- Внутри блока — по месяцам даты начала, заголовок месяца без года. Турнир,
  который идёт через границу месяцев, стоит в месяце начала. Турниры с одной
  датой начала — по младшему возрасту (порядок списка возрастов выше), затем
  по названию. Названия сравниваются по кодам символов, не `localeCompare`:
  порядок `localeCompare` зависит от ICU, и сервер с браузером могли бы
  разойтись при гидрации. Внутри одного регистра кириллицы без «ё» порядок
  совпадает с алфавитным.
- **Строка** — не ссылка, без подсветки при наведении: сроки, название, второй
  строкой «город, база» и возрасты через запятую. У идущего — метка «Идёт»
  (`StatusBadge`, вид меток статуса тот же, что «Состоялось» у событий).
  Строки «Завершённых» приглушены (`text-muted-foreground` у названия), метки
  у них нет: смысл передаёт заголовок блока.
- **Сроки** без года: «14–20 сентября» (внутри месяца — короткое тире без
  пробелов), «28 сентября — 4 октября» (через месяц — длинное с пробелами),
  «19–21 февраля» (точные даты).

## Устройство страницы

Схема адреса и loader маршрута сборка оставляет в общем чанке, который
грузится на каждой странице сайта; в ленивый чанк страницы уходит только
компонент. Поэтому:

- схема адреса берёт значения фильтров из `src/lib/tournament-filters.ts`,
  который из модуля данных импортирует только типы;
- loader получает записи динамическим импортом — модуль данных собирается в
  свой чанк, который предзагружается только на `/tournaments`.

Проверено сборкой 02.10.2026: при статическом импорте данные лежали в общем
`index-*.js` (395 019 байт против 356 163 на `main`); после разделения —
отдельный `tournaments-*.js` (35 472 байт), общий чанк 357 830 байт.

Отдельные турниры поиск не индексирует и в карту сайта не попадают: страница —
одна запись в `src/lib/search-registry.ts` и одна в
`src/routes/sitemap[.]xml.ts`.

## Порядок обновления

1. Антон присылает новую версию календаря файлом (картинка или PDF) и
   называет, какой это календарь. Сами файлы в репозиторий не кладутся:
   репозиторий публичный, а проект календаря ФТР — не публикация ФТР.
2. Агент переносит турниры по правилам разбора (ниже), обновляет у источника
   дату версии, а при необходимости — статус и период. Числа сторожа по
   месяцам правятся тем же PR.
3. В докладе — изменения против прежней версии: какие турниры добавлены,
   какие убраны, какие сдвинуты (по срокам, месту, возрасту), и счёт по
   месяцам. Антон сверяет страницу с файлом глазами.

## Правила разбора

- **Календарь СПб.** Берутся только клетки с заливкой. Курсивные записи без
  заливки — всероссийские соревнования, приведённые для справки, — не
  берутся: они приходят из календаря ФТР. При первой загрузке все шесть
  всероссийских из календаря СПб от 10.09.2026 (пять курсивных и жёлтая
  клетка) совпали с календарём ФТР от 28.05.2026.
- **Заливка → база:** фиолетовая — СЦ «Динамит», оранжевая — ул. Наличная, 44,
  голубая — ТК «Хасанский», жёлтая — «Территория спорта». Адрес из текста
  клетки («(Наличная,44)») из названия убирается.
- **Календарь ФТР.** Каждая непустая клетка — турнир. Город — после последней
  запятой, база — в скобках после города («Москва (НТЦ)»). Колонка «Сроки»
  даёт точные даты внутри недели; если она пуста, сроки — вся неделя. Заливка
  и курсив в календаре ФТР для сайта ничего не значат.
- **Неделя «28-4»** — с понедельника 28-го по воскресенье 4-го следующего
  месяца. Месяц на странице — по дате начала.
- Одно название, место и сроки в нескольких возрастных колонках — одна запись
  с несколькими возрастами.
- **Названия:** заглавные буквы приводятся к обычному регистру («ПЕРВЕНСТВО
  РОССИИ» → «Первенство России»), кавычки — «ёлочки». Сокращения (ВС, МС, МрС,
  КОМ, ОНР, ДФО, ЦФО, СЗФО, НТЦ и т. п.) остаются как в источнике.
- **«Россия: да»** — у всех записей календаря ФТР и у всероссийских
  соревнований из календаря СПб.
- Соревнование, которое есть в обоих календарях (город, сроки и возраст
  совпадают), — одна запись: название из календаря ФТР, база из календаря
  СПб, оба ключа источников, «Россия: да».

## Требования к будущей админке

Найдены на первой загрузке (02.10.2026):

- У турнира может быть несколько возрастов: Кубок Президента, финал «ОНР»,
  «Невская осень» 14–20.09.2026.
- Сроки обычно — неделя календаря; у части турниров — точные даты (пляжный
  теннис).
- Место — город и база. У всероссийских турниров база известна не всегда, даже
  в Петербурге: «МС (командные)», 23–29.11.2026, есть только в календаре ФТР.
- У источника есть дата версии и статус: «проект» или «действующий».
- «Россия» — отдельный признак, а не город. Одно соревнование может стоять в
  обоих календарях.
- Категория РТТ указана у одного турнира («Первенство ТК «Хасанский»»,
  3 категория); отдельным полем пока не ведётся.
- Теннис или пляжный теннис — пока видно только из названия.
- Ссылок на положение, заявки и результаты нет.
