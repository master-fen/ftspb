# Инвентаризация стилей публичной зоны

Снимок кода `main` @ `e93831c`. Только счёт: где какое значение стоит и сколько раз. Решений и рекомендаций здесь нет. Наблюдения UX/UI без решений ведутся в `docs/ux-ui-problems.md`; расхождения стилей — здесь.

Как читать таблицы:

- **Файл:строка** — имя файла без каталога (в области имена уникальны, полные пути — в разделе 1) и строка, где стоит токен класса. В таблицах по элементам (заголовки, обёртки, крошки) — строка открывающего тега.
- **Вхождение** — место в исходнике, а не число отрисованных элементов: карточка из `.map()` — одно вхождение; строка классов в константе, которую используют несколько элементов, — тоже одно.
- Токен считается вместе с цепочкой вариантов: `md:hover:…` и `hover:…` — разные значения.
- `src/components/ui/button.tsx` входит в область (его импортирует шапка), и его токены входят в счёт — включая варианты кнопки, которых публичная зона не рисует (сколько их в каждой таблице — в «Вне списка»).

## Метод

Каждая таблица получена одной из команд ниже (Git Bash, корень репозитория); строка, которой получена таблица, записана под ней. Сырой вывод хранился вне репозитория.

```bash
F=(src/routes/_site*.tsx src/components/site/*.tsx src/components/federation/*.tsx src/components/ui/button.tsx)

# tok V B — токены вне комментариев; V — регулярка по цепочке вариантов (md:hover:…), B — по базе.
# Вывод: файл:строка<TAB>токен.
tok() { V="$1" B="$2" perl -ne '
  BEGIN { $vr = qr/$ENV{V}/; $br = qr/$ENV{B}/ }
  {
    if ($c) { if (s{^.*?\*/}{}) { $c = 0 } else { last } }
    s{/\*.*?\*/}{}g;
    $c = 1 if s{/\*.*$}{};
    s{(^|\s)//.*$}{$1};
    for $t (split /[\s"\x60{}\$;]+/) {
      next unless length $t;
      ($vv, $bb) = $t =~ /^((?:(?:[^:\[\]]|\[[^\]]*\])+:)*)(.*)$/;
      print "$ARGV:$.\t$t\n" if $vv =~ $vr && $bb =~ $br;
    }
  }
  if (eof) { close ARGV; $c = 0 }' "${F[@]}"; }

# el T — JSX-элементы с атрибутом className (многострочно); T — регулярка по имени тега.
# Вывод: файл:строка<TAB>тег<TAB>значение className (пробелы схлопнуты).
el() { T="$1" perl -0777 -ne '
  BEGIN { $tr = $ENV{T} }
  while (/<($tr)(?=[\s>\/])((?:[^>"\x60{}]|"[^"]*"|\x60[^\x60]*\x60|\{(?:[^{}]|\{(?:[^{}]|\{[^{}]*\})*\})*\})*)>/g) {
    $l = 1 + (substr($_, 0, $-[0]) =~ tr/\n//);
    ($tag, $a) = ($1, $2);
    next unless $a =~ /(?<![\w])className=(\{\x60.*?\x60\}|"[^"]*"|\{(?:[^{}]|\{[^{}]*\})*\})/s;
    ($cl = $1) =~ s/\s+/ /g;
    print "$ARGV:$l\t$tag\t$cl\n";
  }' "${F[@]}"; }
```

`tok` режет каждую строку по пробелам, двойным и обратным кавычкам, фигурным скобкам, `$` и `;`, выбрасывает комментарии (`//…`, `/* … */`, включая многострочные JSX-комментарии) и печатает токены, у которых цепочка вариантов подходит под `V`, а база — под `B`. `el` находит открывающие JSX-теги с атрибутом `className` (многострочные и шаблонные значения — тоже).

Сверка перед записью (скрипты сверки — вне репозитория):

- Вывод `tok` по всем выборкам этого документа сверен с независимым разбором TypeScript AST (токены только из строковых литералов и частей шаблонных строк). Сравнение позиционное, по паре «файл:строка, токен»: расхождений 0.
- `el` нашёл 355 элементов. Строк с `className=` — 354 (`git grep -c`), вхождений — 355 (`git grep -o`): на строке `SiteHeader.tsx:254` их два (иконки `X` и `Menu` в тернарнике). Пофайловое число элементов `el` совпадает с пофайловым числом вхождений `className=`.

Обёртка страницы или секции — элемент `<main>`, `<section>`, `<article>`, `<header>`, `<footer>`, `<aside>` с атрибутом `className`, либо любой элемент с `mx-auto` и `px-*`.
