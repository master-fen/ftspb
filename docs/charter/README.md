## Происхождение PDF

Экспорт Word 2010 от 13.03.2017. Штампов регистрации и приложения № 1
(эскиз эмблемы, на которое ссылается п. 9.1) в файле нет. Маркеры списков
остались символами U+F0A7 («▪») и U+F0B7 («•»); дефисы на концах строк
сохранены; номера страниц 2–17 — отдельные строки справа внизу.

## Как перегенерировать

- выгрузку из PDF: `python extract-lines.py ustav.pdf ustav.lines.json`
- контент страницы (`src/lib/charter/content.ts`): `bun run charter:build`,
  проверка актуальности: `bun run charter:check`

Файл `ustav.lines.json` намеренно исключён из prettier (`.prettierignore`):
любое переформатирование сломает контрольный хэш.
