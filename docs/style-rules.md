# Правила оформления публичной зоны

Целевой вид элементов по ролям. Каждая роль — одно определение в одном месте кода; страницы используют его, не копируют строки классов. Пункты с пометкой «открыто» решаются в PR соответствующей категории и вносятся сюда. Фактическое состояние на момент принятия правил — `docs/style-inventory.md` (снимок `e93831c`).

## Принцип

Вид задаётся ролью элемента, не страницей. Одинаковая роль — одинаковый вид на всех страницах. Новая страница собирается из определений ниже и новых локальных значений не вводит.

## Типографика

Шкала размеров одна — стандартная Tailwind (`text-xs` … `text-4xl`). Произвольные размеры `text-[Npx]` не используются. Исключение — два размера заголовка страницы (28 и 36), взятые из эталона: они оформляются именованными значениями темы, не литералами в разметке.

Семейство шрифта — открыто: в коде встречаются `font-sans` и `font-ui`; сколько семейств определено и какое где применяется, выясняется в PR по заголовкам.

| Роль                        | Где                                                                                                            | Целевой вид                                                             | Эталон                                      |

Главная страница — единственное исключение: своего заголовка у неё нет, её блоки «Главное» и «Последние новости» — верхний уровень содержимого и оформляются как заголовок страницы. Любая страница, у которой есть свой заголовок, использует для блоков заголовок блока. Других исключений не добавлять.

Приглушённый текст — только токен цвета (`text-muted-foreground`). Прозрачность текста (`text-*/NN`) не используется: на разных фонах даёт разный оттенок.

Даты — подпись, цветом не выделяются (синие даты в списке событий убираются).

Подписи групп бокового меню — подпись, не заголовок блока.

## Ссылки и наведение

Три типа, к одному не сводятся:

- **Текстовая ссылка** — при наведении текст становится оранжевым (`brand-orange`), с плавным переходом, без подчёркивания. Ссылки в тексте, подвал, меню, крошки, оглавление Устава, ссылки в карточке руководства.
- **Строка списка** — при наведении лёгкая оранжевая подложка на всю строку, текст не меняется. Строки документов, записи списка событий, записи будущего календаря турниров.
- **Карточка новости** — своё поведение (подъём, увеличение фото), не меняется.

Кнопки — вне этих правил, у них своё наведение.

Активной ссылка считается по точному совпадению адреса (крошки, ссылки на раздел в подвале). Пункт бокового меню раздела подсвечивается по разделу — на вложенных страницах остаётся активным.

## Крошки

Один компонент. Точки-разделители, приглушённый текст, текущая страница — не ссылка. Ряд переносится на следующую строку при нехватке ширины; фиксированной высоты нет.

## Карточки

Скругление одно — `rounded-xl`. Рамка одна — `ring-1 ring-black/5`. Тень — открыто (сейчас у 3 карточек из 17).

## Поверхности

Роли: фон страницы, фон приподнятой поверхности (карточки), акцентная подложка (чипы, наведение строки), тёмная поверхность (шапка, подвал). Конкретные токены — открыто до PR по поверхностям. Цвет в разметке — только токеном темы; `style=` с цветом не используется.

## Контейнеры

`max-w-7xl px-4 md:px-6 lg:px-10` — не меняется. Два отклонения в шапке приводятся к нему.

## Запрещено

- `text-[Npx]` и другие произвольные значения там, где есть роль из таблицы выше;
- `style=` с цветом;
- `className` из шаблонной строки с переменной или конкатенации — сканер Tailwind таких классов не видит;
- копирование строки классов роли в другой файл — используется общее определение роли.
