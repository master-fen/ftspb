# Правила оформления публичной зоны

Целевой вид элементов по ролям. Каждая роль — одно определение в одном месте кода; страницы используют его, не копируют строки классов. Пункты с пометкой «открыто» решаются в PR соответствующей категории и вносятся сюда. Фактическое состояние на момент принятия правил — `docs/style-inventory.md` (снимок `e93831c`).

## Принцип

Вид задаётся ролью элемента, не страницей. Одинаковая роль — одинаковый вид на всех страницах. Новая страница собирается из определений ниже и новых локальных значений не вводит.

## Типографика

Шкала размеров одна — стандартная Tailwind (`text-xs` … `text-4xl`). Произвольные размеры `text-[Npx]` не используются. Исключение — два размера заголовка страницы (28 и 36), взятые из эталона: они оформляются именованными значениями темы `--text-page-title` и `--text-page-title-md` (межстрочный интервал 1.18 задан в них же), не литералами в разметке.

Семейство шрифта заголовков — Manrope (`font-sans`): оно входит в объявление утилит `ui-h1`, `ui-h2`, `ui-h3` и на элементах не ставится (решение Антона, #73). `font-ui` (Inter) — текст и интерфейс; семейство основного текста — открыто до PR по тексту. Подписи (`ui-caption`) семейство не задают и сейчас смешаны (#74): Inter там, где `font-ui` стоит на элементе или предке (строки документов, дата и место на странице события, дата в списке событий, подпись под схемой Структуры, «Редакция от …» Устава, подписи полей руководства), Manrope в остальных; `font-ui` на подписях снимается только вместе с решением о шрифте текста.

Главная страница — единственное исключение: своего заголовка у неё нет, её блоки «Главное» и «Последние новости» — верхний уровень содержимого и оформляются как заголовок страницы (`SectionHeading`: тег h2, утилита `ui-h1` — вид задаёт утилита, тег не меняется). Любая страница, у которой есть свой заголовок, использует для блоков заголовок блока. Других исключений не добавлять.

Скрытый заголовок (`sr-only`, h1 главной) роли не несёт: утилита роли на нём не ставится.

Приглушённый текст — только токен цвета (`text-muted-foreground`). Прозрачность текста (`text-*/NN`) не используется: на разных фонах даёт разный оттенок.

Даты — подпись, цветом не выделяются (синие даты в списке событий убраны в #74). Строка «категория · дата» в карточках списка — подпись; надзаголовок — только строка над заголовком страницы.

Подписи групп бокового меню и «Содержание» в колонке полного текста Устава — подпись (утилита `ui-caption`, тег h2 не меняется), не заголовок блока.

## Ссылки и наведение

Три типа, к одному не сводятся:

- **Текстовая ссылка** (утилита `ui-link`) — при наведении текст становится оранжевым (`brand-orange`), с плавным переходом, без подчёркивания. Ссылки в тексте, подвал, меню, крошки, оглавление Устава, ссылки в карточке руководства. Открыто: ссылки в тексте новости (`.news-prose a:hover`): база оранжевая, наведение navy — конфликт с правилом; решение принимается отдельно.
- **Строка списка** (утилита `ui-link-row`) — при наведении лёгкая оранжевая подложка на всю строку (`brand-orange/5`), текст не меняется. Строки документов, записи списка событий, записи будущего календаря турниров.
- **Карточка новости** — своё поведение (подъём, увеличение фото), не меняется.

Кнопки — вне этих правил, у них своё наведение.

Активной ссылка считается по точному совпадению адреса (крошки, ссылки на раздел в подвале). Пункт бокового меню раздела подсвечивается по разделу — на вложенных страницах остаётся активным.

## Крошки

Один компонент. Точки-разделители, приглушённый текст, текущая страница — не ссылка. Ряд переносится на следующую строку при нехватке ширины; фиксированной высоты нет.

## Карточки

Скругление одно — `rounded-xl`. Рамка одна — `ring-1 ring-black/5`. Тень — открыто (сейчас у 3 карточек из 17).

Блок «Читайте также» на странице новости — карточка (фон, рамка, скругление); его заголовок — заголовок карточки, не заголовок блока.

## Поверхности

Роли: фон страницы, фон приподнятой поверхности (карточки), акцентная подложка (чипы, наведение строки), тёмная поверхность (шапка, подвал). Конкретные токены — открыто до PR по поверхностям; исключение — наведение строки: `brand-orange/5` (утилита `ui-link-row`, см. «Ссылки и наведение»). Цвет в разметке — только токеном темы; `style=` с цветом не используется.

## Контейнеры

`max-w-7xl px-4 md:px-6 lg:px-10` — не меняется. Два отклонения в шапке приводятся к нему.

## Запрещено

- `text-[Npx]` и другие произвольные значения там, где есть роль из таблицы выше;
- `style=` с цветом;
- `className` из шаблонной строки с переменной или конкатенации — сканер Tailwind таких классов не видит;
- копирование строки классов роли в другой файл — используется общее определение роли.
