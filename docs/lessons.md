# Уроки

По строке на урок. Это не правила — правила в `CLAUDE.md`,
`docs/process.md` и `docs/style-rules.md`. Это то, на чём уже обжигались:
список читается перед тем, как придумывать проверку.

Уроки, уже записанные в `docs/process.md` (бэкап сверяется с текущим
состоянием объекта, а не просто существует; перестраховка — тоже дефект;
утверждение о коде без сверки — гипотеза), здесь не повторяются.

## Проверки и доказательства

- **Запрос без положительного контроля ничего не доказывает.** SQL «совпадают
  ли размеры обложки и первого фото» дал ноль не потому, что дублей нет, а
  потому, что колонка `width` пуста у всех строк. Подозрительный сам по себе
  ноль — повод проверить, способна ли проверка сработать вообще.
- **Фиксированная пауза в пробе загрузки отказывает на тяжёлых страницах** —
  ровно на тех, ради которых пробу писали. Приём замены — сетевое затишье,
  `docs/environment.md`.
- **Утверждение о классе читает атрибут того элемента, о котором говорит.**
  Поиск подстроки по фрагменту молча захватывает потомков: у обёртки
  `NewsImage` есть `relative`, и «у кнопки нет `relative`» было бы вечно
  красным.
- **Тест на наличие строки проходит при подмене мест.** «В разметке есть `+7`
  и `+6`» зелено и тогда, когда плашки перепутаны; привязываться надо к плитке
  и к классу видимости.
- **Проверка исправления до правки обязана быть красной.** Зелёная до правки
  означает, что замер дефекта не видит.
- **Успех команды — не результат.** Команда изменения размера окна вернула 0,
  а ширину подтверждает только прочитанный после неё `innerWidth`.
- **Контрольное число, достигнутое перекладкой тестов, — подгонка.** Число
  тестов — сторож, а не бюджет: его не «добивают».
- **Число из задания устаревает после каждого мержа** — сверяться надо с
  клоном, а не с текстом промпта.
- **Проба из задания — гипотеза**, а не спецификация: если она не может
  сработать, чинится проба.
- **Формула проверки проверяется на паре без правки** — иначе непонятно, что
  именно она меряет.
- **Сработавшее стоп-условие — не всегда дефект кода**: сначала проверяется
  сама проверка.
- **Умолчание общего компонента доказывается на существующем потребителе**, а
  не на выдуманном примере.
- **Строка манифеста лежит в `.html`** — снимок страницы её содержит, и шум
  порядка `preloads` виден именно там.
- **`bun run` печатает аргументы.** Подтверждено по коду 19.09.2026: вывод
  `bun run typecheck` начинается со строки `$ tsc --noEmit`. Секреты в
  аргументах не передаются.

## Поведение платформы

- **Ограничение количества — не ограничение веса.** Перестройка галереи
  сократила число запросов, а не мегабайты: миниатюра 200 px тянула файл на
  11 МБ. Вес нашёлся случайно, по размерам в выводе другого скрипта.
- **`lazy` в горизонтальной полосе почти ничего не отсекает**: порог загрузки
  больше ширины короткой полосы, а на десктопе длинная видна почти целиком.
  Решение «все кадры с `lazy`» держится на сжатых файлах, а не на `lazy`.
- **`overflow-x: auto` обрезает и по вертикали** — тень снаружи элемента
  требует отступа у контейнера прокрутки.
- **`history.back()` асинхронен**: до `popstate` интерфейс живёт в прошлом
  состоянии, и повторное действие удваивается.
- **`focus()` прокручивает страницу**, если элемент срезан краем окна; для
  возврата фокуса — `preventScroll`.
- **`box-sizing` меняет отсчёт всех размерных свойств**, не только ширины.
- **`ring-1` без цвета — `currentColor`.** Урок прежних итераций; в этом PR не
  переподтверждался (для проверки нужен разбор собранного CSS).

## Работа с источниками и макетами

- **Документ врёт там, где его не трогали.** Срез создаётся правкой
  предыдущего, сверяется только изменённое — и утверждение живёт месяцами.
  Отсюда весь этот перенос: правила и факты о коде лежат рядом с кодом и
  сверяются.
- **Память постановщика — не первоисточник.** Предел History API был назван
  неверно (30 с вместо 10) и поправлен цитатой из исходников браузеров; то же
  с «Tailwind отдаёт произвольный вариант как написано» — на деле сборка
  переписывает его в range-синтаксис.
- **Прежде чем строить фичу — проверить, нет ли её.** «Подкрутить сжатие при
  загрузке» уже жило в `src/lib/image-resize.ts`; тяжёлыми были только файлы
  мигратора.
- **Сетка дизайнера — арифметика, а не переписывание разметки.**
- **Поля макета — остаток, а не число**: они получаются из ширины артборда и
  контейнера.
- **Макет отвечает на вопросы дизайнеру раньше дизайнера** — половина
  вопросов снимается измерением.
- **Токенная правка лучше обёртки** — её проще обратить.
- **Сессия с телефона рождает ветку без ритуала** — такую ветку надо
  досматривать по клону (`docs/process.md`).

## Уже записанное отдельно

В `docs/style-rules.md`, раздел «Уроки #78–#79»: `position: fixed` внутри
предка с `transform`; жадный срез общих концов ломает выравнивание на
повторяющихся блоках; проверка, выведенная из предполагаемого механизма,
проходит вхолостую; правка, снявшая один дефект, может вскрыть второй,
который маскировался; проверка называет наблюдаемое следствие, а не факт
срабатывания.
