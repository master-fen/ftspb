# Раздел «Устав»: верстка по макету

Собрать публичную страницу `/federation/charter` по присланному макету. Реальные документы и серверные данные подключит Claude Code позднее; текущая задача — готовая адаптивная разметка на локальных демонстрационных данных.

## Основная область страницы

- Убрать заглушку «В разработке» и сверстать содержимое Устава:
  - вводный текст;
  - блок «О документе» с полным названием, датой первоначального утверждения и датой действующей редакции;
  - разделы «Что регулирует Устав», «Основные положения», «Содержание Устава»;
  - блок «Полный текст документа» со строками доступных форматов.
- Сохранить существующие шапку, подвал, хлебные крошки и двухколоночный каркас раздела «Федерация».
- Не менять существующий `head()` и не подключать loader: это зона Claude Code.

## Правая колонка

- Оставить действующий навигатор подразделов Федерации с активным пунктом «Устав».
- Только на странице Устава добавить под ним:
  - компактное оглавление «На этой странице» с якорными ссылками на смысловые блоки;
  - карточку «Документ» с названием, датами, форматом и действием скачивания;
  - ссылку на раздел документов Федерации.
- На узких экранах дополнительные блоки правой колонки переходят под основной текст и сохраняют удобный порядок чтения.

## Компоненты и состояния

- Создать отдельные публичные компоненты для оглавления и представления документа/файлов, чтобы Claude Code позднее передал в них реальные данные через props без переделки разметки.
- Использовать иконки файла, просмотра и скачивания из уже подключенного набора и существующие семантические цвета/шрифты проекта.
- До появления настоящих URL действия файлов оформить как явно неактивные элементы, чтобы заглушки не вели на `#` и не имитировали рабочее скачивание.
- Добавить доступные заголовки, aria-подписи и заметный focus-state для ссылок.

## Технические детали

- Изменить только JSX публичной страницы `src/routes/federation.charter.tsx` и условное наполнение правой колонки в `src/routes/federation.tsx`; metadata и серверную загрузку не трогать.
- Создать небольшие компоненты в `src/components/site/` для оглавления, карточки документа и строк файлов.
- Стили задать Tailwind-классами на существующих токенах (`background`, `foreground`, `muted`, `brand-blue`, `brand-orange`, `border`); глобальные токены добавлять только если существующих объективно недостаточно.
- Проверить страницу на desktop и mobile: отсутствие наложений, корректный перенос длинных названий, порядок блоков и работу якорной навигации.

## Граница с работой Claude Code

Позже Claude Code подключит опубликованные документы из хранилища, реальные URL/размеры файлов, loader и при готовности страницы изменит индексирование. В серверные, data-, admin- и test-файлы эта работа не входит.
