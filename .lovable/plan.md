# Раздел «Руководство»: карточки персон с заглушкой фото

Макет — референс, не пиксель-в-пиксель. Верстаем компоненты с временными данными,
подключение реальных данных будет позже.

## Что появится на странице

- Заголовок «Руководство», короткое описание под ним (как сейчас), пометка
  «В разработке» убирается — страница получает реальную структуру.
- Ниже — вертикальный список карточек персон. Каждая карточка: слева
  вертикальное фото, справа текстовый блок:
  - ФИО (заголовок карточки)
  - Должность
  - Дополнительная информация / биография (несколько строк)
  - Контакты: телефон, электронная почта, ссылка на соцсети/новости
- Пока данных нет — 4 карточки-примера с обобщённым текстом («ФИО»,
  «Должность» и т. д.), чтобы было видно раскладку.
- Мобильная версия: фото сверху, текст под ним, единая колонка.
- Правый навигатор раздела «Федерация», хлебные крошки, шапка и подвал —
  без изменений.

## Заглушка фото

Новая заглушка для портрета: спокойный светло-голубой фон карточки сайта,
по центру — обобщённый силуэт человека (голова и плечи, лёгкий контур,
не иконка-аватар из набора), в правом нижнем углу — логотип Федерации
маленьким размером и с низкой прозрачностью, как ненавязчивая вотермарка.
Заглушка используется только в карточках руководства.

## Технические детали

- Новый `src/components/site/PersonPhotoPlaceholder.tsx` — силуэт инлайновым
  SVG на токене `--news-card`, логотип из `@/assets/logo-transparent.png`
  абсолютом в правом нижнем углу с низкой opacity.
- Новый `src/components/site/LeadershipCard.tsx` — карточка персоны, props:
  `name`, `role`, `bio?`, `phone?`, `email?`, `links?`, `photo?`. Без `photo`
  рендерится заглушка. Сетка: `md:grid-cols-[minmax(0,240px)_1fr]`,
  соотношение фото ~3/4, скругления и типографика — существующие токены и
  `font-ui`, без хардкода цветов.
- `src/routes/federation.leadership.tsx` — вместо `SectionPagePlaceholder`
  локальный массив-заглушка (в самом файле, чтобы не трогать `src/data/**`)
  и рендер списка карточек. `head()` и `noindex` сохраняются.
- Другие подразделы Федерации, `SectionPagePlaceholder`, шапка, подвал,
  навигатор — не меняются.
