Собираем главную страницу сайта Федерации тенниса Санкт-Петербурга по присланному макету. Работаем только с фронтендом и моковыми данными — CMS, бэкенд и импорт турниров пока не трогаем.

## Что фиксируем из ответов

- «Матч городов» — отдельный тип Event (не отдельная сущность).
- Коллегия судей — свои новости и свой календарь событий.
- Импорт турниров, форма обратной связи, хостинг и CMS — вне текущей итерации.
- Стек — TanStack Start (текущий проект), моковые данные в TS-файлах.

## Оценка макета и что правим

Стиль и палитра макета сохраняем: белый фон, оранжевый акцент, глубокий синий, тёмно-синий футер, крупные фото-карточки новостей с тёмной подложкой снизу. Правим «детские» огрехи, не меняя дух:

- Шапка выравнивается: логотип слева, горизонтальное меню разделов по центру/справа, иконка поиска справа. Одинаковая высота, один ритм отступов.
- Оранжевая разделительная полоса под шапкой остаётся, но фиксированной толщины и вплотную к контенту (без «провала»).
- Заголовки блоков («Новости · Главное», «Новости · Последнее») — единый стиль: одинаковый размер, одинаковый разделитель (иконка мячика), выравнивание по общей сетке контейнера.
- Сетка новостей блока «Главное»: слева большая карточка (2/3), справа колонка из двух карточек (1/3). Все карточки одной высоты по сетке, единый радиус скругления, единая тёмная подложка-градиент снизу с метаданными (раздел · дата) и заголовком.
- Блок «Последнее»: ровная сетка из 3 равных карточек, тот же радиус, те же пропорции 4:3, единый стиль подписи.
- Все карточки — кликабельные ссылки (пока ведут на `#`, заглушки).
- Футер: логотип слева, две колонки ссылок справа, снизу тонкая линия и мелкий текст с адресом и копирайтом — как на макете, но с выравниванием по общему контейнеру.
- Общий контейнер `max-w` + одинаковые горизонтальные паддинги для шапки, контента и футера, чтобы всё было по одной вертикали.
- Адаптив: на планшете «Главное» становится 1+2 в столбик, «Последнее» — 2 колонки; на мобильном всё в один столбец.

## Разделы навигации (заглушки)

В шапке и в футере кладём полный набор разделов из итерации 3, ссылки пока `#` (страниц ещё нет):

- Главная
- Федерация
- Сборные команды
- Календарь турниров
- Документы
- Коллегия судей
- Клубы города
- Контакты

## Моковые данные

Один файл `src/data/mock.ts` с массивами:

- `featuredNews` — 3 записи для блока «Главное» (1 крупная + 2 боковые). Поля: `id`, `category` («Турниры» / «Сборная»), `date`, `title`, `excerpt?`, `cover`.
- `latestNews` — 3 записи для блока «Последнее». Те же поля, `excerpt` не обязателен.
- `navSections` — массив разделов для шапки и футера.
- `siteMeta` — адрес, копирайт, ссылки на «Политика конфиденциальности» и «Пользовательское соглашение».

Изображения — плейсхолдеры (генерируем 3–4 фото в стиле макета: кубок на корте, командное фото, награждение) в `src/assets/`. Иллюстративные «нарисованные» карточки блока «Последнее» пока заменяем на такие же фото-плейсхолдеры, чтобы избежать разнобоя стилей; при желании потом вернём иллюстрации.

## Дизайн-токены

В `src/styles.css` добавляем семантические токены под палитру макета (значения в `oklch`, регистрируем в `@theme inline`):

- `--brand-orange` — оранжевый акцент (полоса под шапкой, hover, иконка-разделитель).
- `--brand-blue` — синий для ссылок навигации и иконки поиска.
- `--brand-navy` — тёмно-синий фон футера.
- `--surface` — фон страницы (мягкий белый как на макете).
- Радиус карточек — единый (`--radius` ~ 12px), тень мягкая.
- Типографика: гротеск для интерфейса (например, Manrope) + жирные заголовки; загружаем через `<link>` в `__root.tsx`.

Все компоненты используют только эти токены — никаких хардкод-цветов.

## Структура кода

- `src/routes/__root.tsx` — обновляем `head()` (title/description для сайта Федерации), подключаем шрифты через `<link>`, оставляем `<Outlet />`.
- `src/routes/index.tsx` — главная: `<SiteHeader />`, `<FeaturedNewsSection />`, `<LatestNewsSection />`, `<SiteFooter />`.
- `src/components/site/SiteHeader.tsx` — логотип, навигация, поиск, оранжевая полоса.
- `src/components/site/SiteFooter.tsx` — логотип, колонки ссылок, адрес, копирайт, юридические ссылки.
- `src/components/site/SectionHeading.tsx` — заголовок «Новости · Главное» с иконкой-разделителем.
- `src/components/site/NewsCard.tsx` — карточка новости с обложкой, подложкой-градиентом, метаданными и заголовком; проп `size: "hero" | "default"`.
- `src/components/site/FeaturedNewsSection.tsx` — сетка 2/3 + 1/3 (2 карточки в колонку).
- `src/components/site/LatestNewsSection.tsx` — сетка 3 равных карточек.
- `src/data/mock.ts` — моковые данные.
- `src/assets/` — 3–4 сгенерированные фото-обложки + простой логотип-плейсхолдер (или оставляем текстовый логотип «Федерация тенниса Санкт-Петербурга» в фирменных цветах, если не хотим тратить генерации).

## Что специально не делаем на этой итерации

- Не заводим Lovable Cloud и таблицы БД.
- Не создаём отдельные роуты под остальные разделы (только заглушки-ссылки в меню).
- Не подключаем реальный поиск (иконка есть, действия нет).
- Не рисуем страницу новости, календарь, карточки клубов и т.д.
