# Раздел «Федерация»: навигатор подразделов

Собираем каркас раздела по макету Frame 57: боковой навигатор справа, хлебные крошки, заголовок страницы. Наполнение подразделов (включая «Руководство») пока пустое — только заголовок и пометка «В разработке».

## Структура раздела

```text
/federation                     -> редирект/страница-вход раздела
  О федерации
    /federation/about           О федерации
    /federation/leadership      Руководство
    /federation/structure       Структура
    /federation/charter         Устав
  Деятельность
    /federation/news            Новости (заглушка, отдельная страница)
    /federation/events          События
    /federation/documents       Документы
```

Существующие файлы `federation.events.tsx` и `federation.documents.tsx` переезжают на новый общий каркас. `/federation` показывает «О федерации» как страницу-вход раздела.

## Что делает пользователь

- В верхнем меню «Федерация» → «О Федерации» открывает `/federation/about`; справа виден навигатор со всеми подразделами, активный подсвечен.
- Клик по любому пункту навигатора переключает страницу без потери навигатора.
- Хлебные крошки: Главная ● Федерация ● О федерации ● Руководство — в уже принятом стиле (Inter 14/500, круглый разделитель 10px).
- На мобильном навигатор идёт под контентом (или сверху, как аккордеон), в одну колонку.

## Навигатор (по макету)

- Карточка: фон `#FAFAFA`, рамка 1px `rgba(1,58,108,.1)`, радиус 30px, ширина ~413px в правой колонке.
- Заголовки групп («Федерация», «Деятельность») — крупнее и темнее, пункты — приглушённый серый.
- Активный пункт: плашка `rgba(1,58,108,.2)` радиус 5px + левая полоса 7px цвета `#013A6C`.
- Все цвета берём из существующих семантических токенов (`brand-blue`, `surface` и т.п.), новых хардкод-классов не добавляем; при нехватке — новый токен в `src/styles.css`.

## Страница подраздела (пустой шаблон)

Заголовок 48px (Inter 500), под ним краткое описание-плейсхолдер, пометка «В разработке» оранжевым. Контейнер `max-w-7xl` + `px-4 md:px-6 lg:px-10` — как на остальных страницах, чтобы шапка/подвал совпадали по колонкам.

## Технические детали

- `src/routes/federation.tsx` — layout-роут: `SiteHeader`, крошки, сетка «контент + навигатор», `<Outlet />`, `SiteFooter`.
- `src/routes/federation.index.tsx` — `/federation` (О федерации), плюс листовые роуты `federation.about.tsx`, `federation.leadership.tsx`, `federation.structure.tsx`, `federation.charter.tsx`, `federation.news.tsx`, `federation.events.tsx`, `federation.documents.tsx`.
- Новые компоненты: `src/components/site/FederationSidebar.tsx` (структура пунктов + активное состояние через `useRouterState`), `src/components/site/Breadcrumbs.tsx` (переиспользуем стиль со страницы новостей), `src/components/site/SectionPagePlaceholder.tsx`.
- Дерево пунктов навигатора — константа в `src/components/site/FederationSidebar.tsx` (не в `src/data/**`, это зона Claude Code).
- В `src/data/mock.ts` подпункты меню «Федерация» переводим на `/federation/about` и `/federation/news` (сейчас указывают на `/federation/events` и `/federation/documents`).
- У каждого листа свой `head()`: уникальные title/description/og, `robots: noindex` пока раздел пуст.
- `ComingSoon.tsx` не трогаем — он остаётся для других разделов сайта.
