# Раздел «Федерация»: чистка структуры

Сейчас «О Федерации» встречается трижды на одной странице: пункт верхнего меню, заголовок группы в правом навигаторе и пункт внутри группы — отсюда дубль в крошках («Главная • Федерация • О Федерации • Руководство»).

## Что предлагаю изменить

1. Крошки — три уровня, без промежуточной группы:
   `Главная • Федерация • Руководство`
   Название группы («О Федерации» / «Деятельность») в крошки не выносим: это визуальная группировка навигатора, а не уровень адреса.

2. Переименовать пункты, чтобы имя пункта не повторяло имя группы:
   - группа **О Федерации**: «Общая информация», «Руководство», «Структура», «Устав»
   - группа **Деятельность**: «Новости Федерации», «События», «Документы»
   (`/federation/about` остаётся адресом «Общей информации»)

3. Верхнее меню: раздел называется «Федерация», в выпадающем списке — те же две группы. Так одно и то же слово перестаёт повторяться на трёх уровнях.

4. `/federation` открывает «Общую информацию» (редирект на `/federation/about`), а не пустой каркас.

5. «Новости Федерации» ведут на уже готовый раздел новостей с фильтром «Федерация» (`/news?category=federation`) вместо второй пустой страницы новостей. Дубля новостей в проекте не будет.

## Технически

- `src/components/site/FederationSidebar.tsx` — новые подписи в `federationNav`, `findFederationCrumbs` возвращает только пункт (без группы).
- `src/routes/federation.tsx` — крошки `Главная / Федерация / <пункт>`.
- `src/routes/federation.index.tsx` — `beforeLoad` с `redirect` на `/federation/about`.
- `src/routes/federation.news.tsx` — удаляется; пункт навигатора ссылается на `/news` с параметром категории.
- `src/routes/federation.about.tsx` — заголовок «Общая информация», `head()` обновляется.
- `src/data/mock.ts` — подписи верхнего меню («Федерация», «Новости Федерации»).
- Наполнение подразделов по-прежнему пустое, с пометкой «В разработке».
