## Что делаем

Перерисовываем десктопное верхнее меню по макету, сохраняя стиль и цвета. Отношусь к макету как раньше: сохраняю дух и композицию, но выравниваю пропорции, отступы и типографику. Мобильная версия остаётся с бургером — правим только раскрытие «Федерации».

## Изменения в данных (`src/data/mock.ts`)

- **Набор пунктов шапки не трогаем** — оставляем текущий список из `navSections` как есть (Главная, Новости, Федерация, Сборные команды, Календарь турниров, Документы, Коллегия судей, Клубы города, Контакты).
- Расширяем тип `NavSection`, чтобы поддержать вложенность:
  ```ts
  export type NavSection = {
    label: string;
    href: string;
    children?: { label: string; href: string }[];
  };
  ```
- У пункта «Федерация» добавляем `children`: «Мероприятия», «Документы Федерации» (href = `#` — заглушки).

## Десктопная шапка (`src/components/site/SiteHeader.tsx`)

- Активный раздел (совпадает с текущим маршрутом или является родителем открытого подменю) получает короткую **тёмно-синюю** подчерк-линию под текстом (2px, ширина по тексту) — цвет `--color-brand-blue`, как на макете под «Федерация». Проверил по картинке: подчерк действительно синий, не оранжевый.
- Пункты с `children` рендерятся как кнопка: по hover/фокусу/клику разворачивается подменю **в потоке шапки** (не абсолютный поповер), выровненное влево под своим родителем. Оранжевая полоска шапки естественно уезжает вниз ровно так же, как на макете.
- Подпункты — тем же тёмно-синим полужирным, размер чуть меньше; ховер → оранжевый.
- Кнопка поиска (круглая, тёмно-синяя, с лупой) — справа, вертикально по центру относительно первой строки.
- Типографика — Manrope 700, размеры и трекинг близко к текущему.
- Открытие/закрытие «Федерации»: hover открывает, уход курсора закрывает; для клавиатуры — клик/Enter, повторный клик и Esc закрывают. Одновременно раскрыт только один раздел.

## Мобильная шапка

- Бургер и список сохраняем.
- «Федерация» становится раскрываемой секцией: тап разворачивает «Мероприятия» и «Документы Федерации» с отступом слева; шеврон меняет направление.

## Технические детали

- Состояние раскрытия — локальный `useState<string | null>` в `SiteHeader`.
- Активное состояние — через `useRouterState().location.pathname`; родитель активен, если pathname равен его `href` или начинается с любого `href` дочернего пункта.
- Стили — только Tailwind-классы и существующие переменные (`--color-brand-blue`, `--color-brand-orange`). Никаких хардкод-цветов.
- Оранжевая полоска шапки — последний блок в `<header>`, автоматически сдвигается вниз при появлении строки подменю над ней.
- Трогаем только `mock.ts` (тип + `children` у «Федерации») и `SiteHeader.tsx`.
